About this project

Final-year project at Bahria University Islamabad for the Neural Networks & Fuzzy Logic course (8A).

Goal: predict diabetes risk using ANN (accuracy-focused) and ANFIS (interpretability-focused), with SHAP for transparency — addressing the black-box and crisp-boundary limitations described in the proposal.

Methodology — 4 phases (as per proposal)

  1. Preprocessing — zero values replaced with median, min-max normalization, 80/20 stratified split.
  2. ANN — feed-forward MLP with ReLU hidden layers and Sigmoid output, trained with Adam.
  3. ANFIS — Takagi-Sugeno neuro-fuzzy with Gaussian membership functions, rules from Fuzzy C-Means clustering, consequents warm-started from logistic regression.
  4. Explainable AI — SHAP for per-feature attribution, plus extracted human-readable fuzzy rules from ANFIS.
