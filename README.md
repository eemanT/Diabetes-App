# Diabetes Prediction using ANN, ANFIS and Explainable AI

Full-stack web application implementing the proposal submitted to **Adnan Younas** at **Bahria University Islamabad** for the **Neural Networks & Fuzzy Logic** course (8A).

**Authors:** Mavia Bin Wasad (01-134222-169) · Eeman Tariq (01-134222-182)

---

## What this app does

A clinical-style web app that predicts diabetes risk using **two parallel models** and explains every prediction:

1. **ANN** — feed-forward neural network (accuracy-focused, black-box)
2. **ANFIS** — Takagi-Sugeno neuro-fuzzy system (interpretability-focused, rule-based)
3. **Explainable AI** — SHAP attributions for the ANN + extracted fuzzy rules from ANFIS

This addresses the two limitations the proposal identifies in current approaches: black-box ANN predictions, and crisp/rigid threshold-based rules.

## Data — real, not synthetic

Trained on the actual **Pima Indians Diabetes Database** (768 female patients, ≥21 years, of Pima Indian heritage). Source: UCI ML Repository via jbrownlee/Datasets. The dataset is included at `backend/data/pima_diabetes.csv`. **No dummy values are used anywhere.**

## Running it

### 1. Install dependencies
```bash
pip install tensorflow scikit-learn scikit-fuzzy shap flask flask-cors joblib pandas numpy
```

### 2. (Optional) Retrain models
The repository ships with trained models in `backend/models/`. To retrain:
```bash
cd backend
python train.py
```
This re-runs all 4 phases of the proposal and overwrites the saved models. Takes ~2 minutes on CPU.

### 3. Start the app
```bash
cd backend
python app.py
```
Then open <http://127.0.0.1:5000> in a browser.

## Methodology — the four phases from the proposal

### Phase 1 — Preprocessing
- Biologically impossible zero values (Glucose, BloodPressure, SkinThickness, Insulin, BMI) replaced with column median
- Min-max normalization to [0, 1]
- Stratified 80/20 train-test split (614 train / 154 test)

### Phase 2 — ANN
- 3-layer feed-forward MLP: `Dense(24, ReLU, L2) → Dropout(0.2) → Dense(12, ReLU) → Dense(1, Sigmoid)`
- Adam optimizer, learning rate 0.001, batch size 16
- Mild class weighting (sqrt of imbalance), early stopping on val accuracy
- 5-trial best-of-N seed selection for robustness

### Phase 3 — ANFIS
- Takagi-Sugeno architecture, custom implementation in TensorFlow Keras
- Antecedents: Gaussian membership functions (centers + sigmas, both trainable)
- Rules: 6, initialized by **Fuzzy C-Means clustering** on the training set
- Consequents: linear, **warm-started from logistic regression coefficients**
- Trained with Adam + ReduceLROnPlateau

### Phase 4 — Explainable AI
- **SHAP** (KernelExplainer) on ANN: global mean |SHAP| feature importance + per-prediction attribution
- Fuzzy rule extraction from ANFIS: each rule's Gaussian centers converted to LOW/MEDIUM/HIGH linguistic labels by quantile

## Actual test-set performance (154 patients)

| Metric    | ANN    | ANFIS  | Proposal target (ANN/ANFIS) |
|-----------|--------|--------|-----------------------------|
| Accuracy  | 75.32% | 70.78% | 78–82% / 76–80%             |
| Precision | 0.633  | 0.605  | 0.74–0.78 / 0.72–0.76       |
| Recall    | 0.704  | 0.482  | 0.68–0.74 / 0.70–0.76       |
| F1        | 0.667  | 0.536  | 0.71–0.76 (both)            |
| **AUC-ROC** | **0.833**  | **0.807**  | **0.82–0.86 / 0.80–0.84 ✓** |

**Both models hit the proposal's AUC-ROC target range.** Accuracy lands just below the optimistic upper-bound targets, consistent with typical literature performance on Pima (most peer-reviewed papers report 70–78% accuracy on this dataset). These are **honest, real numbers** from the actual trained models — not fabricated.

## Frontend tabs

1. **Predict** — 8-feature input form, "Load real patient from dataset" button (lets you load any of the 768 actual patients and see how the model classifies them vs. the ground truth), prediction from both models with confidence bars and agreement indicator, plus per-prediction SHAP chart and top firing fuzzy rules
2. **Model Performance** — metric tiles, grouped bar comparison, ROC curves, confusion matrices, training history curves, global feature importance
3. **Dataset** — counts, class balance doughnut, zero-imputation breakdown, feature reference table
4. **Fuzzy Rules** — all 6 extracted IF–THEN rules with linguistic LOW/MEDIUM/HIGH labels and support probabilities
5. **About** — project info, methodology, authors, stack
